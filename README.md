# my money log 💰

회원가입 없이 쓰는 간단한 가계부 웹페이지입니다. `index.html` 파일 하나와 Supabase DB로 동작합니다.

## 사용법

👉 **바로 사용하기: https://geuna-seo.github.io/my-money-log/**

또는 `index.html`을 내려받아 브라우저로 열어도 됩니다.

## 기능

- 수입·지출 기록 (날짜, 분류, 금액, 메모)
- 월별 달력에서 날마다 수입·지출 금액 요약 (지출이 많은 날일수록 칸이 붉게 표시)
- 날짜를 누르면 그날 내역만 보기
- 이번 달 남은 돈, 무지출 데이, 하루 평균 지출
- 분류별 지출 비율
- 내역 수정·삭제, 다크모드, CSV 내보내기

## 데이터 저장 (Supabase)

- 내역은 Supabase DB(`ledger_entries` 테이블)에 저장됩니다. 회원가입은 없습니다.
- 처음 접속하면 브라우저마다 무작위 **장부 코드**가 만들어지고, DB 보안 정책(RLS)이 그 코드와 일치하는 내역만 읽고 쓰도록 막습니다.
- 오른쪽 위 🔑 버튼에서 장부 코드를 복사해 다른 기기에 입력하면 같은 장부를 함께 쓸 수 있습니다.
- 장부 코드를 아는 사람은 누구나 그 장부를 보고 고칠 수 있으니 남에게 알려주지 마세요. 코드를 잃어버리면 장부를 되찾을 수 없습니다.
- 예전 버전에서 브라우저에 저장해 둔 기록은 처음 접속할 때 자동으로 DB로 옮겨집니다.
- DB 구조는 [`supabase/schema.sql`](supabase/schema.sql)에 있습니다.
